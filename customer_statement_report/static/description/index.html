Customer Statement Report

Generate professional customer account statements and send them by email — individually or in bulk — directly from Odoo Accounting.

Odoo 19 Accounting ✓ Bulk Email ✓ PDF + ZIP ✓ Unicode / Greek

📍 Accessible from Accounting → Reporting

Find Customer Statement under Accounting → Reporting → Management

⚡ Key Features

📄

Professional PDF Statement

Company logo, address, VAT, invoice table with opening balance, due dates, and overdue highlighting in red.

👥

Bulk Email Wizard

Send statements to all customers in one click. Filter by positive, negative, or zero balance before sending.

📦

ZIP Export

Select multiple customers and download a ZIP with one PDF per customer — perfect for batch printing.

💳

Dynamic Bank Details

Bank account, IBAN, and BIC auto-populated from your company settings. No hardcoding needed.

📅

Flexible Date Control

Set From/To period for transactions plus an independent Statement Date for the header.

🌐

Unicode / Greek Support

DejaVu Sans font + UTF-8 wkhtmltopdf fix ensures correct rendering of Greek, Arabic, and accented characters.

🧾 Simple Wizard Interface

Set date range, pick customers (or leave empty for all), then Print PDF or Send by Email

Select specific customers using tags — supports multi-select

✉️ Send by Email

Single customer: opens Odoo compose dialog pre-filled with subject, body, and PDF attached

📨 Bulk Email Wizard

Review all customers with transactions — see outstanding balances, select/deselect, send in one click

Filter by: Green (owed to you) · Red (credit balance) · Gray (zero) — total amounts shown in badges

Instant confirmation with count of emails sent

🖨️ PDF Output

Professional A4 statement: company logo, customer address, transaction table, totals, bank details

🚀 How It Works

1

Open Wizard

Accounting → Reporting → Customer Statement

2

Set Dates

Choose period and optional statement date

3

Select

Pick customers or leave empty for all

4

Print or Send

PDF, ZIP, single email, or bulk send
