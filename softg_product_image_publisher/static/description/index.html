The Problem

Marketplaces and shopping feeds want real, cache-friendly URLs that end in .jpg or .png. Odoo's built-in /web/image/ route returns images without file extensions, with internal-looking paths, and often fails marketplace validators outright.

Worse, many feed consumers only re-fetch images when the URL string itself changes. With Odoo's native URLs, your image updates never propagate downstream.

The Solution

↹ Bulk operations

Select N products from list view → Action → Generate Image URLs. Done.

⚙ Config in UI

Change disk path and URL prefix via System Parameters. No code edits needed.

Installation Requirements

This module writes images to a static directory served by nginx (or any web server). A basic nginx configuration is included in the user guide. No other external dependencies required.

Installation Steps

  1. Install the module from the Odoo Apps Store
  2. Configure nginx static directory (see user guide)
  3. Set disk path and URL prefix in System Parameters
  4. Go to Products → select all → Action → Generate Image URLs
  5. Submit image URLs to your marketplace feed
