The Problem

Odoo's default product URLs end with the database ID — useful for the router, ugly for customers and search engines. Worse, third-party themes often inject SKU prefixes too.

You also can't rename a product without breaking every inbound link, search engine cache, customer bookmark, and marketplace listing pointing at the old URL.

Before & After

Before /shop/65492163-dell-latitude-5330-notebook-warranty-1960
After /shop/dell-latitude-5330-notebook-13-3-fhd-intel-core-i5

Both URLs resolve on day one. Existing bookmarks, search-engine cached pages, and marketplace listings keep working — the legacy URL is served by Odoo's native route, the new clean URL by the module's custom controller. Zero broken links on install.

What You Get

⊕ Clean URLs

Name-based slugs replace the default name-id pattern everywhere Odoo emits product URLs.

↺ Auto 301 Redirects

Rename a product and a 301 from old URL to new is created automatically. SEO juice preserved.

◉ public_url Field

Absolute storefront URL on every product, ready to feed Bazaraki, Google Shopping, Facebook.

# Smart Slugs

slug(name) → SKU → product-id fallback chain. Auto-handles collisions and special characters.

✂ Auto-Truncation

Long names truncate at word boundary, default 80 chars. Configurable via System Parameter.

⌚ Daily Cron

Backfills missing slugs and refreshes URLs automatically. Set and forget.

↹ Bulk Actions

Regenerate URLs across hundreds of products from the list view in seconds.

⌂ No Infra Changes

Pure Odoo module. No nginx config, no DNS changes, no Cloudflare setup. Install and go.

⚙ Multi-Website

Respects per-website domain configuration. Falls back to web.base.url for single-site deployments.
