Why you need this

Every marketplace invents its own XML schema.

Bazaraki expects <ads><ad> with rubric and district. Google Shopping wants <rss><item> with the g: namespace. Facebook uses yet another shape. Most shops pay €50–200/month per connector or hand-roll brittle scripts that break on every product rename.

Without this module· One Python script per marketplace · Hard-coded field paths break on rename · Bazaraki rubric IDs typed manually · No preview before going live
With this module· One UI form per marketplace · Field mappings edited in 2 clicks · 212 Bazaraki rubrics bundled in · Preview first 3 items button · Live URL — marketplaces poll directly
