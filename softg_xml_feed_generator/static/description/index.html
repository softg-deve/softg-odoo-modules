The Problem

Every marketplace wants your product catalogue as XML. Bazaraki expects <ads><ad> with <rubric> and <district>. Google Shopping wants <rss><item> with the g: namespace. Facebook Catalog uses the same RSS shape but different required attributes.

Most Odoo shops solve this by paying for a separate per-marketplace connector (€50–200/month each), or by hand-rolling brittle Python scripts that break every time a product field is renamed.

The Solution

Build a Bazaraki feed in 30 seconds: New Feed → Load Bazaraki Preset → fill in shop contact info → Generate. Your live URL is at yourshop.com/feed/bazaraki.xml — Bazaraki polls it every hour.

What You Get

⊕ Live Polling URL

Every feed served at /feed/<code>.xml. Marketplaces poll directly — no SFTP uploads, no manual file delivery.

⚙ Editable Mappings

Each XML element is one row: tag, source, value, transform. No code. Reorder, add, remove from the UI.

⚡ Three Presets

One-click load for Bazaraki Cyprus, Google Shopping (g: namespace), Facebook Catalog.

◉ Four Source Types

Product field path, static value, template with placeholders, image collection (multi-image wrapper).

✂ Built-in Transforms

Uppercase, lowercase, strip HTML, round to 2 decimals, ISO date — applied per mapping row.

# Bazaraki Catalogue

212 rubrics + 168 districts pre-loaded. Fuzzy auto-match your Odoo categories. Bulk action on category list.

⌚ Cache + Cron

Served from ir.attachment cache. Configurable refresh interval. Hourly cron regenerates active feeds.

↹ CDATA Support

Wrap any element in CDATA for HTML descriptions, URLs with ampersands, or any value with special characters.

▤ Per-product Fields

Condition, brand, warranty months, year, model override, delivery flag — on a new Marketplace Feed tab.

Installation

  1. Install the module from the Odoo Apps Store
  2. Go to Website → Feed Generator → New Feed
  3. Click "Load Bazaraki Preset" (or Google Shopping / Facebook)
  4. Fill in your shop name and contact details
  5. Click Generate — your live URL is ready immediately
  6. Submit the URL to Bazaraki / Google / Facebook
