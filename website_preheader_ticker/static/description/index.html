Up and running in 3 steps

1

Install the module

Go to Apps → search "Website News Ticker Preheader" → Install. Default welcome messages appear immediately on your website after installation.

2

Add your messages

Navigate to Website → Configuration → Preheader Ticker → Messages tab. Delete the defaults and add your own. Drag to reorder. Toggle to enable/disable without deleting.

3

Customize the look

Switch to the Settings tab. Click the color swatches to pick any background, text and separator color. Set the scroll speed. Save. Done.
