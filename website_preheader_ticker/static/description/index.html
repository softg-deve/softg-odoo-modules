Up and running in 3 steps

1
Install the module
Apps → search "Website News Ticker Preheader" → Install. Default messages appear immediately on your website.
2
Add your messages
Website → Configuration → Preheader Ticker → Messages tab. Delete the defaults and add your own. Drag to reorder, toggle to enable/disable.
3
Customize the look
Settings tab → pick colors using the full color picker → set scroll speed → Save. Done.
